# OpenReel 6-Step Workflow

| Step | Skill | What Happens | Output |
|---|---|---|---|
| **0. Setup** | `start-factory` | Checks Node/Remotion, runs onboarding interview, renders 4 real theme previews in the creator's topic, locks `STRATEGY.md`, `BRAND.md`, `TOOL_MODE.md`, and `brand.config.ts` | Personalized factory |
| **1. Ideas** | `make-idea` | Proposes 5 ideas passing the 5-point filter ("Why follow?" + proof + clear mental model) | Chosen idea + `reels/NN_slug/` |
| **2. Script** | `make-script` | Researches facts, writes 3–5 scored hooks, runs Delete Test, maps beats to visuals | `reels/NN_slug/script.md` |
| **3. Visuals** | `make-visuals` | Adapts to Mode 1–4: pure Remotion scenes, camera/screen shot list, or AI prompts matching brand colors | `reels/NN_slug/visual_plan.md` |
| **4. Build** | `build-reel` | Builds `captions.json`, composes `reel.json` (or custom TSX), checks still frames, renders `1080×1920` `.mp4` + cover PNG | `reels/NN_slug/out/reel.mp4` + `cover.png` |
| **5. Package** | `package-post` | Writes Instagram, TikTok, YouTube Shorts, and Facebook captions + pinned comment + optional giveaway setup | `reels/NN_slug/captions_social.md` |
