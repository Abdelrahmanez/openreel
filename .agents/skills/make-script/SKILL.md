# make-script: Retention Script & Hooks

## Read First
1. `docs/STRATEGY.md` (voice, language/dialect, face vs faceless)
2. `docs/BRAND.md` (tone, pacing, theme direction)
3. `docs/TOOL_MODE.md` (visual capabilities)

## Rules for High-Retention Scripts
1. **State the payoff in the first 3–5 seconds:** Hook with a contrarian truth, live result, or sharp pain/mistake — never waste seconds 0–5 on preamble.
2. **3–5 Candidate Hooks (Score out of 100):** Write at least 3 distinct hook types (Contradiction, Specific Number/Proof, Direct Result Demo, Pain/Mistake) and recommend the strongest (`>= 80/100`).
3. **Frame-0 On-Screen Hook Text (3–7 words):** Short, high-contrast headline designed to appear from Frame 0 alongside 1 highlighted keyword.
4. **Radical Simplification + Delete Test:** Replace textbook jargon with everyday spoken words. If deleting a sentence leaves the core insight intact, delete it.
5. **No Generic AI Filler:** Never open with "Hey guys", "In today's video...", "Welcome back", or robotic sign-offs ("And that's it!").
6. **Natural CTA:** Only include a comment keyword CTA if the reel genuinely shares a real tool, template, or resource.

## Available Scene Types for Beat Mapping
Map every beat (2–4 seconds max per beat) to one of OpenReel's 10 real scene types:
- `hook` — Frame-0 kinetic hook card
- `talking-head` — Full-bleed camera A-roll with optional chest `hookBanner`, zoom punch, or callout chip (Mode 2)
- `media` — Image or video clip (`full`, `framed-card`, or `phone-mockup`) with Ken Burns / pan motion (Modes 2–4)
- `split` — Dual vertical split screen (e.g., screen recording top + camera bottom) (Mode 2)
- `stat` — Animated big number counter + delta badge + progress bar
- `steps` — Numbered sequential step cards (`01`, `02`, `03`)
- `compare` — Old vs. New side-by-side comparison (`✕` vs `✓`)
- `quote` — Editorial quote / golden closer with highlighted key phrase & source
- `bar-chart` — Animated horizontal comparison bars with live numbers
- `cta` — Closing takeaway / comment CTA card

## Output (`reels/NN_slug/script.md`)
Write:
- Header (`Reel`, `Theme`, `Mode`, `Target length ~2.4 words/sec`)
- Candidate hooks + recommended pick + Frame-0 text
- Beat-by-beat script table: `Beat # | Spoken Line | Visual On Screen | Scene Type`
- Fact/source links list

Ask the creator to read the spoken lines aloud once and tweak any phrasing so it sounds 100% like them before locking the script.
