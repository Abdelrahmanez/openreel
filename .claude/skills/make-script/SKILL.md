# make-script: Retention Script & Hooks

## Read First
1. `docs/STRATEGY.md` (voice, language/dialect, face vs faceless)
2. `docs/BRAND.md` (tone & pacing)
3. `docs/TOOL_MODE.md` (visual capabilities)

## Rules for High-Retention Scripts
1. **State the payoff in the first 3–5 seconds:** Never hide what the viewer gets until the end; hook with a clear promise, contradiction, or live result.
2. **3–5 Candidate Hooks (Score out of 100):** Write at least 3 distinct hook types (Contradiction, Specific Number/Proof, Direct Result Demo, Pain/Mistake) and recommend the strongest one (`>= 80/100`).
3. **Frame-0 On-Screen Hook Text (3–7 words):** Short, punchy headline designed to appear from Frame 0 alongside a single highlighted keyword.
4. **Radical Simplification + Delete Test:** Replace textbook jargon with everyday language. If deleting a sentence leaves the core insight just as clear, delete it.
5. **No Generic AI Filler:** Never open with "Hey guys", "In today's video...", "Welcome back", or robotic filler transitions.
6. **Natural CTA:** Only include a comment keyword CTA if the reel genuinely offers a real template, guide, or resource to send.

## Output (`reels/NN_slug/script.md`)
Write:
- Header (`Reel`, `Theme`, `Mode`, `Target length ~2.4 words/sec`)
- Candidate hooks + recommended pick + Frame-0 text
- Beat-by-beat script table: `Beat # | Spoken Line | Visual On Screen | Scene Type (hook / stat / steps / compare / media / cta)`
- Fact/source links list

Ask the creator to read the spoken lines aloud once and tweak any phrase so it sounds 100% like them before locking the script.
