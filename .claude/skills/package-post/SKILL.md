# package-post: Platform Captions & Launch Checklist

## Read First
1. `reels/NN_slug/script.md`
2. `docs/STRATEGY.md`

## Produce `reels/NN_slug/captions_social.md`
Write everything in the reel's language/dialect (`ar` or `en`):

1. **Instagram Reels Caption:**
   - **Line 1:** Text hook (the only line shown before `...more`)
   - **Lines 2–4:** Extra bonus detail or takeaway + natural search keywords (plus the exact keyword CTA if it's a giveaway reel)
   - **Sources** (if applicable) + **3–5 relevant hashtags** (never > 5)
2. **TikTok Caption:**
   - 1–2 punchy lines with primary search words right at the beginning + 3–5 hashtags. (Upload clean `out/reel.mp4`, never an IG-watermarked file.)
3. **YouTube Shorts:**
   - **Title (<= 60 chars):** clear curiosity/value hook
   - **Description:** 2 short lines + sources + 2–3 hashtags
4. **Facebook Reels:**
   - Conversational 1st-line hook + brief 2–3 line story + 2–3 hashtags.
5. **Pinned Comment:**
   - Either a smart discussion question OR the exact Comment-to-DM trigger instruction matching the video.

Remind the creator to upload `reels/NN_slug/out/cover.png` as the **custom cover** and verify the 3:4 profile grid crop.
