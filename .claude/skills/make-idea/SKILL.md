# make-idea: Niche-Matched Idea Generation

## Read First
1. `docs/STRATEGY.md` (niche, target audience, language, face/faceless preference)
2. `docs/TOOL_MODE.md` (so every proposed idea actually fits the creator's available tools)
3. Existing folders inside `reels/` to avoid repeating topics

## The 5-Point Idea Filter (Every Idea Must Pass All 5)
1. **Scroll-Stopping Curiosity:** Can the core tension fit in a 4–7 word Frame-0 hook?
2. **Clear Takeaway ("Why Follow?"):** Does the viewer learn a repeatable framework, real mechanism, or useful tool — not throwaway trivia?
3. **Real Proof:** Is there a verified source, live demo, concrete number, or reproducible step behind it?
4. **Tool-Mode Fit:** Can it be produced cleanly using the creator's `docs/TOOL_MODE.md` without buying new subscriptions?
5. **Fresh Angle:** Does it avoid generic "5 AI tools" / recycled clickbait cliches?

## Output
Present **5 ranked ideas** in the creator's language, each with:
- Working title / Frame-0 hook promise
- What the viewer walks away understanding
- Proof / demo source
- Visual plan summary (for their Mode 1–4)

Once the creator picks an idea, create `reels/NN_slug/` (e.g., `reels/01_my_topic/`) and move directly into `make-script`.
